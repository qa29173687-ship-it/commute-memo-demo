# 出門備忘 DEMO

這是給「出門備忘」App 看的**可點示範頁**，不是正式產品。

- 所有項目、時間、檔期都是**範例資料**
- 資料只存在瀏覽器的 localStorage，沒有連 Firebase，也沒有用付費 API
- 正式版預計做成 Android App：桌面小工具、下班順便做、通知或鬧鐘

線上示範：https://qa29173687-ship-it.github.io/commute-memo-demo/

## 畫面

- **桌面小工具（首頁）**：先列出下班順便做，再列出上班帶出門；可打勾、快速新增
- **下班順便做（主力）**：每項有「拿」或「買」標籤；常用項目（拿包裹、買牛奶等）可一鍵加入今天
- **上班帶出門**：常用項目一鍵加入；只在前一晚通知（預設 22:00）問你明天要帶的東西準備好了嗎，沒有早上鬧鐘
- **淘寶採購清單**：只在 App 裡，不會出現在小工具。可填備註、手動輸入打折日期、提前當天／1／3／7 天並選通知或鬧鐘。打勾後到已買，可清除已買
- **模擬通知／鬧鐘**：通知是畫面上的橫幅；鬧鐘是全螢幕，可按關閉或稍後

頁面底部可按「恢復範例資料」重來。
