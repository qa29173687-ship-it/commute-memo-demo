# 出門備忘 DEMO

可點的靜態 DEMO（繁體中文、手機優先），示範「下班順便做」和「上班帶出門」備忘錄。

- 新增項目可選今天、明天、指定日期或重複；晚上 6 點後新增預設是明天。
- 前一晚提醒（預設 22:00 通知）分成「明天出門帶」和「明天下班順便」。
- 隔天下班提醒（17:50）會列出當天要順便做的，包含前一晚先加的項目。
- 桌面小工具可用「看今天／看明天」預覽，並有「模擬前一晚提醒」「模擬明天下班提醒」。
- 淘寶採購清單只在 App 裡，打折日期要自己輸入。

範例資料存在瀏覽器 localStorage（`commute-memo-demo-v4`），不會寫到雲端。
