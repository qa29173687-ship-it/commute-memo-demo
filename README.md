# 出門備忘 DEMO

可點的靜態 DEMO（繁體中文、手機優先），示範「下班順便做」備忘錄。

- 下班順便做就是今天要做的事，可標「拿」或「買」，也可先加明天、指定日期或重複。
- 17:50 提醒今天還沒做完的項目。
- 晚上 10 點若還有沒打勾的，會問要不要延到明天（可單筆或全部延後、標已完成或刪除），並同時列出明天下班要做的事。
- 採購清單在另一頁，不在小工具上。每件都要自己選日期，沒趕上也能隨時改日期再提醒。

範例資料存在瀏覽器 localStorage（`commute-memo-demo-v5`），不會寫到雲端。
