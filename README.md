# 出門備忘 DEMO

這是給「出門備忘」App 看的**可點示範頁**，不是正式產品。

- 所有項目、時間、地點都是**範例資料**
- 資料只存在瀏覽器的 localStorage，沒有連 Firebase，也沒有用付費 API
- 正式版預計做成 Android App：固定時間通知、離開家／公司時提醒、桌面小工具

線上示範：https://qa29173687-ship-it.github.io/commute-memo-demo/

## 畫面

- **今天**：只顯示今天要帶、要順便做的項目，打勾後當天記住；隔天自動重來
- **上班帶出門／下班順便做**：新增、編輯、刪除項目
- **重複**：每天、指定星期幾（例如週三倒垃圾）、只提醒一次（打勾後消失）
- **提醒設定**：上班日固定時間（預設早上 07:30、下班 17:50）、離開地點提醒（DEMO 僅模擬）、沒打勾再提醒
- **模擬通知**：早上出門前、下班前、離開公司三種情境，點通知會打開清單
- **桌面小工具預覽**：今天還沒做完的項目，可快速新增

頁面底部可按「恢復範例資料」重來。
