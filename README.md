# 出門備忘 DEMO

這是給「出門備忘」App 看的**可點示範頁**，不是正式產品。

- 所有項目、時間、檔期都是**範例資料**
- 資料只存在瀏覽器的 localStorage，沒有連 Firebase，也沒有用付費 API
- 正式版預計做成 Android App：桌面小工具、通知或鬧鐘、想買清單

線上示範：https://qa29173687-ship-it.github.io/commute-memo-demo/

## 畫面

- **桌面小工具（首頁）**：今天要帶出門、下班順便做的項目，可在小工具上打勾或快速新增
- **上班帶出門／下班順便做**：新增、編輯、刪除；每天、指定星期、只提醒一次
- **提醒設定**：早上、下班各自設定時間和星期，並選擇「通知」或「鬧鐘」
- **模擬通知／鬧鐘**：通知是畫面上的橫幅；鬧鐘是全螢幕，可按關閉或稍後。提示音要先按「聽鬧鐘」才會響
- **想買的東西**：只在 App 裡，不會出現在小工具。可填備註、手動輸入打折日期、提前 當天／1／3／7 天，並選通知或鬧鐘。打勾後移到「已買」

頁面底部可按「恢復範例資料」重來。
